⚠️ Where the Agent Was Wrong & Why

Primary error patterns identified during pipeline auditing:

  • Enterprise Multi-Protocol Omission: Platforms like Salesforce, Slack, and Google Ads offer quickstart personal API keys in developer sandboxes, causing Pass 1 to omit mandatory enterprise OAuth 2.0 Connected Apps requirements until Pass 2 cross-checking.
  • CLI Utility Misclassification: Open-source terminal utilities (Sherlock, Mermaid CLI) were initially flagged as REST APIs due to third-party web wrapper search results. Resolved by enforcing CLI classification rules.
  • Login-Wall Redirection: Platforms like Podio and Harvest redirect unauthenticated public documentation requests (e.g. /developer) to internal SSO login walls, failing raw DOM extraction.
  • Client-Side Single Page Applications (SPAs): Documentation hubs built on React/Stoplight return empty HTML shells to standard HTTP fetchers, requiring deep-link endpoint resolution.

4. THE AGENT

Agent Architecture & Execution Pipeline

Six-stage autonomous research and verification pipeline enforcing evidence grounding.

Stage 1
Search
Extracts root hints, computes derived endpoints (developer.*, docs.*), and executes field-separated queries.
Tools: SearchRouter, DDG, GitHub API
Stage 2
Extract
Fetches live HTML with rotating user-agents, strips noise via BeautifulSoup, and extracts structured records via LLM.
Tools: AsyncFetcher, Pydantic, Groq
Stage 3
Verify
Audits evidence URLs, performs fuzzy sliding-window token matching on page text, and runs an LLM claim judge.
Tools: VerificationEngine, difflib
Stage 4
Re-research
Runs an independent orthogonal research pass on high-risk fields and triggers stricter Pass 2 prompt refinement for flagged rows.
Tools: CrossCheckEngine, Pass 2 Prompt
Stage 5
Human Check
Generates stratified 20-app sample across 10 categories into human_check.csv for manual review.
Tools: StratifiedSampler, accuracy.py
Stage 6
Output
Exports validated deliverables, updates verification metrics, and compiles self-contained dashboard.
Tools: JSON/CSV Exporter, build_index_html

⚠️ Where a Human Was Needed (Honest Counts)

While the agent autonomously extracted and verified documentation for the majority of the catalog, human review was strictly required in the following areas:

  • Rows Flagged for Human Review: Exactly 3 apps flagged in verification_report.json / human_queue.csv due to cross-check discrepancies or missing documentation.
  • Stratified Human Check: Exactly 20 apps manually audited across all 10 categories in human_check.csv.
  • Authentication Walls: Unauthenticated redirects to SSO/login walls on platforms like Podio and Harvest required manual verification of public mirrors.
  • Enterprise Licensing Nuance: Ambiguous tiering (e.g. Zoho CRM offering self-serve REST keys but sales-gating enterprise webhooks) required human interpretation.
